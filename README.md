
# 🚀 AI Data Analyst Pro Dashboard

## 📌 Project Overview

AI Data Analyst Pro Dashboard is an interactive data analytics application developed using Python and Streamlit. It helps users analyze datasets without manually writing SQL queries or creating charts from scratch.

Users can upload CSV or Excel files, preview their data, calculate summary statistics, visualize numerical data, and generate AI-powered business insights using the OpenAI API.

## ✨ Key Features

- **Dataset Upload:** Upload CSV and Excel files for analysis.
- **Data Preview:** Explore uploaded datasets through an interactive table.
- **KPI Analysis:** Calculate mean, maximum, and minimum values for selected numerical columns.
- **Data Visualization:** Generate bar charts, line charts, and pie charts.
- **AI-Powered Insights:** Generate business insights and recommendations from dataset summary statistics.
- **Data Export:** Download the uploaded dataset as a CSV file.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- OpenAI API

## ⚙️ Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/streamlit-python-project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd streamlit-python-project
   ```

3. Install the required libraries:

   ```bash
   pip install streamlit pandas matplotlib openpyxl openai
   ```

4. Configure your OpenAI API key securely using an environment variable or Streamlit secrets.

5. Run the application:

   ```bash
   streamlit run "AI Data Analyst Pro Dashboard.py"
   ```
